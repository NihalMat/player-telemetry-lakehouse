# Resume copy

## Project title

Player Telemetry Lakehouse and Game Analytics | Scala, Spark, Kafka, Iceberg, Hadoop, Cassandra

## Two bullet version

* Built a Scala and Spark reference platform for synthetic gameplay telemetry using a GameAnalytics-style event contract. Validated and deduplicated Kafka events, pseudonymized player identifiers, and stored replayable history in Apache Iceberg using a Hadoop catalog and HDFS.
* Modeled D1, D7, and D30 retention, session quality, level start, fail, and completion funnels, economy flows, in-app purchases, and metrics by app build. Published privacy-thresholded aggregates to Cassandra, orchestrated daily jobs and Iceberg maintenance with Airflow, and reproduced the design with a deterministic one million event validation harness.
